## 1. Docs extraction + unofficial OpenAPI (on `main`: `1280510` + `41bc4c0`)

- `scripts/extract_bexio_api_docs.py` — stdlib-only; **downloads https://docs.bexio.com live by default** (verified byte-identical vs. your browser snapshot; `--source` accepts a saved HTML/MHTML file). Re-run any time and `git diff` shows the docs changes.
- **`docs/bexio-openapi.json` / `.yaml`** — unofficial OpenAPI 3.0.3: 190 paths, 310 operations, 88 request-body schemas, 525 responses with 310 JSON examples, bearerAuth. JSON≡YAML (js-yaml verified). **Contact: Rico Metzger (@titaniumcoder), rico.metzger@titaniumcoder.com**, with an explicit "not bexio AG's responsibility" disclaimer.
- The generated **Markdown reference was removed** per your feedback (the OpenAPI spec carries the same information in a standard format). The script can still render it locally for humans with `--markdown`.
- `docs/UNTRUTHS.md` — docs-vs-reality divergences (kept as the one hand-maintained document).
- README documents the spec, the regeneration command and that the library stays hand-written (spec = reference, not source of truth — no generated code breaking clients).
- Known limitation (true of the docs site itself): nested schemas are collapsed in the rendered page — nested children aren't recoverable; such fields are typed `object`/`array` with schema names where the docs name them (e.g. the timesheet `range` variant).

- Deprecated fields kept running and flagged (`@typedoc` notes + `x-` annotations); nothing removed.
